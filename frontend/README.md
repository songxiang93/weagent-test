# Smart Conversation Frontend

Vue.js frontend for smart conversation application.

## Features

- Chat interface with message history
- Image upload and display
- Responsive design
- Loading states and error handling

## Setup

1. Install dependencies:
```bash
cd frontend
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

The development server will run on port 3000 and proxy API requests to the backend on port 8080.
